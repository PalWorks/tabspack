# Store listings

One listing, written once, submitted to three stores with the differences each
one forces. Task T-505.

| File | For |
|---|---|
| [listing.md](listing.md) | The text: name, summary, description, category, and the permission justifications |
| [submission.md](submission.md) | What each store asks for at upload time, and the answers |
| `../../assets/store/` | Icons and promo tiles, generated by `node scripts/gen-assets.mjs` |

Screenshots are pictures of the real interface, taken by `npm run smoke`, which
writes them to `.tmp/shots`. Take them on a clean profile with a believable
session open, never with real browsing in the frame.

The permission answers come from [PLAN.md](../../PLAN.md) Table P8 and must not be
improvised at upload time. If a reviewer asks for something these files do not
answer, that is a decision to record, not a sentence to invent: PLAYBOOK section 8.
