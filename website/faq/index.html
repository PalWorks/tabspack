FAQ

Questions, answered properly.

If the answer you need is not here, the contact page has three ways to ask, and a person reads all of them.

Is TabsPack free?

Yes, completely. There is no paid tier, no trial, no account and no advertising. It is published under the MIT licence and the source is on GitHub. The pricing page explains why, at length, because "free" in a browser extension is usually the beginning of a worse story.

Does TabsPack send my tabs anywhere?

No. TabsPack requests no host permission when you install it, so out of the box it cannot reach any address on the internet at all. Your tabs are read only when you ask for an export, and they are written to a file on your own machine. The only request TabsPack can ever make is a support message you write yourself and press Send on, and your browser asks your permission before that happens.

Which browsers does it work in?

Chrome, Microsoft Edge and Firefox, from one source tree, and any other Chromium browser that accepts Chrome Web Store extensions. Tab groups need a browser that has tab groups; where they do not exist the tabs are restored ungrouped and TabsPack tells you so.

Can I move a session from Chrome to Firefox, or the other way?

Yes. A .tabspack.json file written in one restores in the other. Windows, tab order, pinned tabs and the active tab come back in all of them. Where a browser lacks a feature the file describes, TabsPack restores everything it can and names what it could not do, rather than failing the whole restore.

What exactly comes back when I restore?

The windows and their position and size, every tab in its original order, which tabs were pinned, which tab was active in each window, tab groups with their names, colours and collapsed state, and which tabs were muted. What does not come back is anything that would be a security problem to carry: you are not logged into anything by restoring a pack.

Will restoring hundreds of tabs freeze my machine?

No. Restored tabs are opened asleep by default: they appear in the strip with their title and address and load nothing until you click one. A measured restore of two hundred real pages takes about nine seconds and leaves one hundred and ninety-nine of them unloaded. If you would rather they all load, there is a setting.

What happens to tabs held by a suspender extension?

TabsPack unwraps them. Suspenders such as The Great Suspender and the extensions that replaced it park your tab on their own internal page and hide the true address inside that page's address. No other browser can reopen it, and if the suspender is ever removed from the store the tab is lost. TabsPack reads the real address back out, both when exporting and when importing, and tells you how many it recovered.

Can I open a TabsPack file without the extension?

Yes. It is ordinary JSON against a published schema. A text editor opens it, a script can read it, and git diff will tell you what changed between two of them. That is deliberate: your session should not be locked inside an extension that might be delisted.

What other formats can it import?

OneTab exports, Session Buddy JSON and CSV, Tab Session Manager exports, browser bookmarks in Netscape HTML, Markdown link lists, flat JSON and a plain list of addresses. TabsPack identifies the file by reading it rather than trusting its name, and reports what it found before opening anything.

What can it export to, besides its own format?

A plain list of addresses, a flat JSON file, and CSV. The interface says what each one loses before you choose it: a list of addresses cannot carry windows, groups or order, and TabsPack would rather tell you that than let you find out later.

Why does it ask for a tab groups permission?

Because without it the browser does not expose the tab groups interface at all, so a group's name and colour cannot be read and your export would quietly contain unnamed groups. TabsPack asks for it before you export rather than after, which is the point at which the information would otherwise be lost. Refusing is fine: the tabs still come back grouped, just unnamed.

Does it work with private or incognito windows?

Private windows are excluded by default and TabsPack cannot see them at all unless you take two deliberate steps: allow the extension in private mode in your browser's own settings, and switch the option on inside TabsPack.

What about pages a browser will not let an extension open?

Browsers refuse to let extensions open their own internal pages, such as settings or the extensions list. TabsPack keeps those addresses in the file so nothing is lost, and on restore it opens a page listing the ones it was not allowed to open so you can click them yourself.

Firefox says the add-on "appears to be corrupt". Is it broken?

No. Release Firefox refuses to install any extension Mozilla has not signed and reports that refusal with an unhelpful sentence about corruption. Until the listing is live on addons.mozilla.org, install it through about:debugging and Load Temporary Add-on, which lasts until you close Firefox, or use Firefox Developer Edition with xpinstall.signatures.required set to false.

What are the keyboard shortcuts?

Alt + Shift + E exports every window, Alt + Shift + D exports the current one, and Alt + Shift + S saves a snapshot. Your browser owns these and you can change them; TabsPack reads back whatever the browser actually accepted and shows it in About.

Where are snapshots stored, and do they sync?

In your browser's local extension storage, on the machine where you made them. They are not synced across your devices, they survive a browser restart, and they are removed if you uninstall the extension. Files you have exported are never touched.

Does an export contain anything sensitive?

No. A pack holds addresses, titles and structure. Never cookies, session tokens, authorization headers, form contents or page contents. An exported file cannot be used to sign in as you anywhere, and that is written into the format specification as a requirement rather than left to the implementation.

Is the source available?

Yes, all of it, under the MIT licence, at github.com/PalWorks/tabspack, including the build checks that enforce the privacy claims and the thirty-nine decision records explaining why it is built the way it is.
