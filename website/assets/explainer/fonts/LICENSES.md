# Fonts

Self-hosted, so neither the explainer nor the art pipeline loads anything from a
font service at runtime. All three are under the SIL Open Font License 1.1,
which permits bundling and redistribution.

| File | Family | Role | Source |
|---|---|---|---|
| `bricolage-grotesque.woff2` | Bricolage Grotesque, variable, latin | Display: headlines only | Google Fonts, OFL 1.1 |
| `figtree.woff2` | Figtree, variable, latin | Body and captions | Google Fonts, OFL 1.1 |
| `jetbrains-mono.woff2` | JetBrains Mono, variable, latin | File names and counts | Google Fonts, OFL 1.1 |
